# GitHub profile setup

1. Open the public repository **DivyanshRai27/DivyanshRai27**.
2. Upload this package while preserving the folders:
   - **README.md**
   - **assets/hero.svg**
   - **profile-3d-contrib/profile-night-rainbow.svg**
   - **.github/workflows/profile-3d.yml**
3. Commit the files to the default branch.
4. Open **Actions → GitHub-Profile-3D-Contrib → Run workflow**.
5. After the first successful run, refresh your profile. The placeholder graph will be replaced by your live 3D contribution calendar.

The workflow then refreshes the graph automatically every day at approximately 3:00 AM IST. GitHub's default workflow token is sufficient for public contribution data; no personal access token is needed.
